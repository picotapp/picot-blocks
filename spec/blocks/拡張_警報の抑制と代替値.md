# 拡張：警報の抑制（プログラム）と代替値（PB_AnaMon・PB_BinMon）v0.2

根拠の表記：[一次] は各社の公開マニュアルで確かめたこと（文書番号・章）。「独自」はこのライブラリの設計判断で、理由を書く。

対象：`PB_AnaMon_基本版.md`・`PB_BinMon_基本版.md` の拡張版。**基本版のデータの並びの後ろに足す**（共通仕様 2 章、AI-10）。基本版と同じ FB に入れるか、拡張版の FB を別に作るかは論点 4。
共通仕様：`../common/01_共通仕様_HMI接続まわり.md` 4 章（A-4：基本版は検出の有効・無効だけ。**運転員の棚上げ（Shelve）は HMI 側**。プログラムの抑制は拡張版）

## 0. 警報を止める 3 つの仕組み（どこに持つか）

| 仕組み | 誰が | 目的 | 持つ場所 |
|---|---|---|---|
| 無効化（Disable） | エンジニア | 計器が無い・使わない警報を外す | **ブロック（基本版の Inh。もうある）** |
| **抑制（Suppress）** | **プログラム** | 設計で決めた条件で警報を出さない（例：ポンプ停止中は吐出圧の L を出さない） | **ブロック（この拡張）** |
| 棚上げ（Shelve） | 運転員 | 鳴り続けて邪魔な警報を、時間を決めて一時的に止める | **HMI（Node-RED）。決定済み（A-4）** |

Rockwell は 3 系統をすべてブロックに持つ [一次 RM013]。ISA-18.2 の用語（Out of service・Suppressed by design・Shelved）とほぼ 1 対 1。PICOT は棚上げを HMI に置く（時間切れで戻す、記録する、が警報管理側の仕事のため。A-4）。

## 1. プログラムによる抑制（Suppressed by design）

- 入力 `Supp`（BOOL）を足す。TRUE の間、設定 `SuppMask` で選んだ警報を**出さない**。
  - AnaMon：SuppMask の bit0 HH・1 H・2 L・3 LL・4 計器故障（既定 16#000F：計器故障は抑制しない）
  - BinMon：bit0 動作・1 入力異常（既定 16#0001）
- 抑制中に条件が成立している警報は、**別のワード `SUPALM`**（ALM と同じビットの並び）に出す。画面で「抑制中だが条件は成立している」を見られるようにする（抑制中の警報が見えないと、抑制が外れないまま危険な状態に気付けないため。独自）。
- **抑制が変えるのは ALM ワード（画面に出す警報）だけ**。BOOL の出力（HH・H・L・LL・Fail・ActAlm）は抑制の前の判定のまま出す（論点 5）。インターロックの原因につないだ HH などは、抑制しても効く。
- **抑制は警報の判定（ヒステリシス）を止めない**。Supp が FALSE に戻ったスキャンで、条件が成立している警報はそのまま出る。
- 戻ったときの遅延（ポンプ起動直後のしばらくは L を出さない）は、`SuppOffT`（s、既定 0）で持つ：Supp が FALSE になってから SuppOffT の間は抑制を続ける。
- STS に「抑制中」のビットは足さない（品質と関係ない）。DIAG bit6（AnaMon）・bit4（BinMon）に「抑制中」を出す。

## 2. 代替値（Substitute value）

伝送器が壊れて修理を待つ間、決めた値で運転を続けるための値。**模擬（テスト用）とは目的が違う**。

| | 模擬（基本版にある） | 代替値（この拡張） |
|---|---|---|
| 目的 | 試験：警報やインターロックの動きを確かめる | 運転の継続：壊れた計器の代わりに決めた値を使う |
| PV | 模擬値 | 代替値 |
| 警報 | 模擬値で判定する | **判定しない**（代替値は本当の値でないので、HH などを出さない）。計器故障は出したまま |
| 品質（STS bit3〜4） | Good ＋ 操作された値（bit6） | **Uncertain ＋ 操作された値（bit6）** |
| `Bad` 出力 | FALSE | **FALSE**（調節計を MAN に落とさない。代替値で運転を続けたいため） |
| 書ける人 | エンジニア | エンジニア（論点 2） |

- 要求の口：AnaMon 項目 4（代替値の入・切）・5（代替値）。BinMon 項目 4・5（代替値は 0/1）。
- **入にできるのは、計器故障のときだけ**にするか、いつでもか（論点 3）。案：いつでも（故障しそうな計器を先に外す場面がある）。
- 代替値の入・切は保持する（PLC を入れ直しても続く）。

## 3. Modbus の並び（基本版の後ろ）

| ブロック | 位置 | 中身 |
|---|---|---|
| AnaMon | 36 | SUPALM |
| | 37 | VALX：bit0 Supp（入力）・bit1 抑制中・bit2 代替値 入 |
| | 38 | SuppMask |
| | 39 | 予備 |
| | 40〜41・42〜43 | SubValue・SuppOffT |
| BinMon | 20 | SUPALM |
| | 21 | VALX（同上。bit3 代替値） |
| | 22 | SuppMask |
| | 23 | 予備 |
| | 24〜25 | SuppOffT |

- SuppMask・SuppOffT は設定（エンジニア、要求の口 項目 22・23）。

## 4. HMI

- 警報の一覧に「抑制中」を出すか（出さない、別の一覧、など）は HMI の作業。Node-RED は SUPALM から作れる。
- 代替値で運転中は、PV の横に「代替」の印（品質 Uncertain と操作された値）。今の HMI の品質の表示で出せる。

## 6. 論点（決定済み 2026-11-26：すべて案どおり）

| # | 論点 | 決定 | 理由 |
|---|---|---|---|
| 1 | 棚上げ（運転員）を PLC に持つか | **持たない**（HMI のまま。A-4 の決定どおり） | 時間切れ・記録は警報管理の仕事。PLC に持つとタイマーと記録の領域が要る |
| 2 | 代替値を書ける人 | **エンジニア** | 本当の値でない値で運転を続ける判断は重い。Rockwell も保守員だけに許している [一次 RM013 p.21–22] |
| 3 | 代替値を入にできる条件 | **いつでも** | 故障しかけの計器を先に外す場面がある。別案：計器故障のときだけ |
| 4 | 基本版の FB に足すか、拡張版の FB（PB_AnaMonX など）を別に作るか | **基本版の FB に足す**（入力 Supp はつながなければ FALSE、代替値は切で始まるので、基本版と同じ動き） | FB が 2 つあると利用者が迷う。データの並びは後ろに足すので、基本版の番地は変わらない |
| 5 | 抑制で BOOL の出力（HH など）も止めるか | **止めない**（抑制は ALM ワードだけ。基本版の「HH は ALM と同じ内容」を「抑制の前の判定」に変える） | 警報を抑制したら、HH につないだインターロックまで止まる、という事故を防ぐ。出力を新しく足さずに済む |

## 7. 注意（インターロックとの関係）

- 抑制は**画面に出す警報（ALM ワード）だけ**を止める。BOOL の出力・PV・Active は変えないので、インターロックは抑制に影響されない（論点 5）。
- 代替値は PV を変える。**代替値で運転中、その PV から作る HH などの判定は止まる**（2 章：警報を判定しない）。その計器を原因にしたインターロックも効かなくなるので、代替値を入れるのはバイパスと同じ重さの操作になる（エンジニアだけにする理由。論点 2）。

## 8. 細かい決まり（テストベクタと実装の元）

- 8-1 設定に足すもの（保持領域）：`SuppMask`（WORD）・`SuppOffT`（REAL、s）・`SubOn`（BOOL、代替値の入・切。保持する値）・`SubValue`（AnaMon は REAL、BinMon は BOOL）。**つながない・0 のままなら基本版と同じ動き**（SuppMask 0 は何も抑制しない。既定値 16#000F・16#0001 は利用者が入れる値の目安）。
- 8-2 抑制中 ＝ `Supp` が TRUE、または Supp が FALSE になってからの時間が SuppOffT 未満。Supp が FALSE の各スキャンで時間に dt を足し、SuppOffT 以上で抑制をやめる（SuppOffT 0 なら Supp が FALSE になったスキャンでやめる）。Init では Supp の今の値から始める（時間は 0）。
- 8-3 `ALM` ＝ 抑制の前の警報 AND NOT（抑制中なら SuppMask、でなければ 0）。`SUPALM` ＝ 抑制の前の警報 AND（抑制中なら SuppMask、でなければ 0）。HH・H・L・LL・Fail・ActAlm の BOOL は抑制の前のまま。
- 8-4 優先順：停止中 ＞ 模擬 ＞ 代替値 ＞ 通常。
- 8-5 代替値のあいだ：AnaMon の PV ＝ SubValue（フィルタを通さない）、HH〜LL は判定しない（FALSE）、計器故障は判定する（Fail・ALM bit4 は出る）。BinMon の Active ＝ SubValue（遅延なし）、ActAlm は判定しない、入力異常は判定する。どちらも品質 Uncertain・原因 計器・STS bit6、`Bad` = FALSE。
- 8-6 代替値を切にしたスキャンは Init と同じ（フィルタ・Active を今の入力に合わせる。模擬を切にしたときと同じ：AnaMon 13-9）。
- 8-7 設定異常に足すもの：SuppOffT が数でない・負、SuppMask の使わないビット（AnaMon bit5 以上、BinMon bit2 以上）が立っている、AnaMon の SubValue が数でない。
- 8-8 要求の口（どちらもエンジニアだけ）：項目 4 代替値の入・切（0/1、ほかは 8）、項目 5 代替値（AnaMon：EuLo〜EuHi の外は 3。BinMon：0/1、ほかは 8）、項目 22 SuppMask（使わないビットが立つ・負なら 12、その中で整数でなければ 8）、項目 23 SuppOffT（0〜3600 の外は 12）。
- 8-9 DIAG：AnaMon bit6・BinMon bit4 ＝ 抑制中。
