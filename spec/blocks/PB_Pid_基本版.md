## 1. 役割

PV（伝送器ブロックの出力）と SP から、操作出力 MV（0〜100 %）を計算する。DCS の調節計と同じ感覚で使えること（G-5）：比例帯 PB（%）、積分時間 TI（s）、微分時間 TD（s）、モード MAN／AUT／CAS。

基本版に入れないもの（拡張版）：偏差警報、PV トラッキング（MAN 中に SP を PV に合わせる）、SP の変化率制限、ゲインスケジュール、フィードフォワード、オートチューニング、出力の変化率制限。

## 2. 計算（速度形）

毎スキャン、MV の**変化分** ΔMV を計算して前の MV に足す（速度形）。

| 記号 | 意味 |
|---|---|
| s | 動作の向き：正動作（PV が上がると MV を上げる）+1、逆動作 −1（設定 `Action`） |
| x | PV をレンジの % にしたもの × s：x = s × 100 ×（PV − EuLo）/（EuHi − EuLo） |
| e | 偏差（% × s）：e = s × 100 ×（PV − SP）/（EuHi − EuLo） |
| K | 比例ゲイン = 100 / PB |
| Δ | 前のスキャンからの変化（Δx = x − 前の x） |
| D | 微分の項（不完全微分）：D = (η·TD·前の D + TD·Δu) / (η·TD + dt)。u は微分をかける信号（基本形 PID は e、I-PD・PI-D は x）。η = 0.1（固定、論点 2）。TD = 0 なら D = 0 |

| アルゴリズム（設定 `Alg`） | ΔMV |
|---|---|
| 0 **基本形 PID**（既定。偏差比例・偏差微分） | K ×（Δe +（dt / TI）× e + ΔD）、D は e から |
| 1 **I-PD**（PV 比例・PV 微分） | K ×（Δx +（dt / TI）× e + ΔD）、D は x から |
| 2 **PI-D**（偏差比例・PV 微分） | K ×（Δe +（dt / TI）× e + ΔD）、D は x から |

- MV ← MV + ΔMV を、MV 下限 `MvLo`〜上限 `MvHi` で切る。**速度形なので、切ったあと積分が溜まり続けない**（リセットワインドアップが起きない）。
- TI = 0 は「積分なし」（論点 2）。
- 式は横河の FF の PID（I-PD・PI-D、K = 100 / PB、速度形）と同じ形 [一次 IM01C25T02-01EN 付録5]。基本形はその比例・微分を偏差にかけたもの。
- 既定を基本形 PID にする。SP を変えると比例（と微分）が偏差の変化にすぐ効くので応答が速い。SP の急変で MV を跳ねさせたくないループは I-PD・PI-D を選ぶ。
- 偏差・PV をレンジの % にする理由：PB を % で設定する DCS の流儀に合わせる（PV の単位に関係なく同じ PB で同じ強さになる）。
- **計算しないスキャン**（MAN、トラッキング、PV 異常、設定異常）では、前の x・e を今の値にし、D = 0 にしておく。dt ≦ 0 のスキャンは計算もせず、前の値も更新しない（時間が進んでいないため。14-3）。そのため **MAN → AUT にしたとき MV は跳ねない**（バンプレス）。

## 3. モード

| モード（MODE ワード） | SP を決める | MV を決める | 運転員の SP 書き込み | 運転員の MV 書き込み |
|---|---|---|---|---|
| 0 MAN | 運転員 | 運転員 | 受け付ける | 受け付ける（MvLo〜MvHi の外は結果 5） |
| 1 AUT | 運転員 | PID | 受け付ける | 断る（4） |
| 2 CAS | 上位（入力 `CasIn`） | PID | 断る（4） | 断る（4） |

その上に、モードを変えずに出力を決める状態が 2 つある：

| 状態 | 条件 | 動き |
|---|---|---|
| **PV 異常** | 入力 `PvBad` が TRUE（伝送器ブロックの `Bad` をつなぐ） | **MAN に落とす**（MV は保持）。PV が戻るまで AUT・CAS にできない（結果 7）。戻っても自動では AUT に戻さない（論点 3） |
| **トラッキング** | 入力 `TrkOn` が TRUE | MV = `TrkVal`（MvLo・MvHi で切らない）。モードは変えない。運転員の MV 書き込みは断る（4）。TrkOn が戻ったら、TrkVal から同じモードで続ける（設定 `TrkEndMan` = 1 なら MAN にする）（論点 5） |

- 優先順：設定異常 ＞ トラッキング ＞ PV 異常（MAN）＞ 運転員のモード。FF の優先順（O/S ＞ IMan ＞ LO ＞ Man ＞ Auto/Cas）と同じ並び [一次]。
- **インターロックで MV を決めた値にする**のはトラッキングで行う（TrkOn にインターロックの動作中、TrkVal に安全側の値）。HMI 基本設計 1.1 の「インターロック中」の行に当たる。
- モードを変えるのは運転員（要求の口 項目 1）。プログラムがモードを変える入力は基本版では持たない。

## 4. カスケード（J-3・J-6）

- 下位の調節計を CAS にすると、SP = EuLo + `CasIn` / 100 ×（EuHi − EuLo）。**CasIn は % で受ける**（上位の MV が 0〜100 % なので、そのままつなげる）（論点 4）。
- CAS にできるのは入力 `CasGood`（上位の MV が使える：上位が設定異常でない、など）が TRUE のときだけ（断る理由 6）。CAS 中に CasGood が FALSE になったら **AUT に落とす**（SP は最後の値のまま）。
- **上位への戻り信号**（FF の BKCAL、ABB の後ろ向き信号に当たる [一次 ABB 3BSE035981 p.97]）を出す：
  - `BkCas`：下位が上位の値を使っている（CAS で、トラッキング・PV 異常でない）
  - `BkSp`：下位の今の SP（%）
- **つなぎ方**：上位の `TrkOn` ← NOT 下位の `BkCas`、上位の `TrkVal` ← 下位の `BkSp`。下位が CAS でない間は上位の MV が下位の SP に追従するので、下位を CAS にした瞬間に SP が跳ねない（バンプレス）。専用のカスケードの仕組みを作らず、トラッキングだけで組める。
- 呼び出し順は上位 → 下位。戻り信号は 1 スキャン遅れて上位に届く（J-6）。順番が逆でも 1 スキャン遅れるだけで破綻しないことをテストベクタで確かめる。
- オーバーライド（J-7）の「選ばれていない側」も同じトラッキング入力でつなぐ（TrkOn ← 選ばれていない、TrkVal ← 選ばれた出力）。セレクタは B-8。
- **CAS 中のアルゴリズム**：Alg が I-PD のときだけ、CAS 中は PI-D にする（論点 1）。上位の指令に素早く追従させるため（FF の PID も CAS で I-PD から PI-D に切り替える [一次]）。基本形 PID・PI-D はそのまま。

## 5. SP と MV の範囲

- SP は EuLo〜EuHi（PV のレンジ）。運転員の SP がレンジ外なら断る（3）。CasIn から計算した SP はレンジで切る。
- MV は MvLo〜MvHi（MAN の運転員の書き込みは範囲外を断る。AUT・CAS の計算は切る）。MvLo・MvHi を変えたら、今の MV が外ならそのスキャンで切る（全モード。トラッキング中を除く。トラッキングが終わったスキャンからは切る）。

## 6. 設定と保持する値

利用者のプログラムの保持領域に置き、`VAR_IN_OUT` で渡す（AnaMon 6.1）。**SP・MV・モードも保持する**（PLC を入れ直しても SP が画面の初期値に戻らない：HMI H-8）。

| 設定 | 型 | 既定値 | 範囲 | 要求の口 |
|---|---|---|---|---|
| `Action` | INT | 0 逆動作 | 0 逆・1 正 | 変えない |
| `Alg` | INT | 0 基本形 PID | 0 PID・1 I-PD・2 PI-D | 変えない |
| `EuLo` / `EuHi` | REAL | 0 / 100 | EuLo ＜ EuHi | 変えない（伝送器のレンジに合わせる） |
| `PB` | REAL | 100 | 1〜1000 % | 項目 10 |
| `TI` | REAL | 20 | 0〜10000 s（0 は積分なし） | 項目 11 |
| `TD` | REAL | 0 | 0〜1000 s | 項目 12 |
| `MvLo` / `MvHi` | REAL | 0 / 100 | 0〜100 %、MvLo ＜ MvHi | 項目 13・14 |
| `TrkEndMan` | BOOL | FALSE | トラッキングが終わったら MAN にする | 変えない |
| `SP` / `MV` / `Mode` | REAL / REAL / INT | EuLo / 0 / 0 | （保持する値） | 項目 1〜3 |

- 範囲は PICOT HMI の `paramRules`（PB 1〜1000、TI 0〜10000、TD 0〜1000、MV 0〜100）と揃えた。
- 既定値 PB 100 %・TI 20 s・TD 0 は仮の初期値（独自。ループごとに調整する）。逆動作を既定にする理由：流量制御など多くのループが逆動作のため（独自）。
- 設定異常（計算できない設定）：NaN・無限大、EuLo ≧ EuHi、PB ≦ 0、TI・TD が負、MvLo ≧ MvHi、Action・Alg・Mode が範囲外。**設定異常のときは MV を保持し、計算しない**（MAN 扱い）。

## 7. 時間・初期化

- dt は AnaMon と同じ（≦ 0 は計算しない、1.0 s 超は打ち切り）。
- `Init`：**モードを MAN にする**。SP・MV は保持した値のまま（論点 6）。前の x・e・D を今の値に。要求の口は処理しない（AnaMon 13-10）。

## 13. 決めたこと（2026-11-24）

| # | 論点 | 決定 |
|---|---|---|
| 1 | アルゴリズム | **決定**：速度形。既定は**基本形 PID**、設定で I-PD・PI-D。I-PD は CAS 中だけ PI-D にする |
| 2 | パラメーター | PB（%）・TI（s）・TD（s）、K = 100 / PB、偏差は PV レンジの %。**TI = 0 は積分なし**。微分は不完全微分で η = 0.1 固定 |
| 3 | PV 異常 | **MAN に落として MV を保持**。PV が戻っても自動では AUT に戻さない（運転員が確かめてから戻す）。今のデモと同じ |
| 4 | カスケード | CasIn は **%**（上位の MV をそのままつなぐ）。上位が使えなくなったら AUT に落とす。戻り信号（BkCas・BkSp）を上位のトラッキングにつなぐだけで、バンプレスなカスケードになる |
| 5 | トラッキング・インターロック | TrkOn で MV = TrkVal（上下限で切らない）。インターロックで MV を決めた値にするのもこれで行う。終わったら同じモードで続ける（設定で MAN にもできる） |
| 6 | 電源投入 | **MAN で始める**。SP・MV・設定は保持した値（PLC を入れ直しても SP が戻らない） |
| 7 | 既定値 | 逆動作、PB 100 %、TI 20 s、TD 0、MV 0〜100 % |

## 15. 外部リセット（オーバーライド用）

オーバーライド（複数の調節計の MV から高・低を選んで 1 つの弁を動かす）で、選ばれていない調節計の積分が暴走しないようにする仕組み。DCS で広く使われる「外部リセット（リセットフィードバック）」と同じ考え方。

- 15-1 入力 `ErfOn`（BOOL）・`ErfVal`（REAL、%）。オーバーライドに使う調節計はすべて `ErfOn` ← TRUE、`ErfVal` ← セレクタの Out（前のスキャンの値）とつなぐ。
- 15-2 ErfOn が TRUE で PID を計算するスキャン（AUT・CAS、トラッキング・PV 異常でない）は、速度形でなく次の形で MV を決める：
  - F ← F ＋（ErfVal − F）× dt /（TI ＋ dt）（ErfVal の一次遅れ。TI = 0 なら F ＝ ErfVal）
  - MV ＝ F ＋ K ×（e ＋ D）（e は偏差、D は微分の項。比例は Alg によらず偏差にかける）
  - 選ばれている調節計では ErfVal ＝ 自分の前の MV なので、比例＋積分（時定数 TI）の調節計と同じ働きになる。選ばれていない調節計の MV は「選ばれた値 ＋ 自分の偏差の比例分」になり、偏差の向きで正しく切り替わる。
- 15-3 ErfVal が数でないスキャンは F を変えない（MV は F ＋ K ×（e ＋ D））。dt ≦ 0 のスキャンも F を変えない。
- 15-4 ErfOn でないスキャン・計算しないスキャンでは、毎スキャン F ＝ MV − K ×（e ＋ D）にしておく（ErfOn にした瞬間・AUT にした瞬間に MV が跳ねない）。速度形の前の値（x・e・D）は、ErfOn で計算したスキャンでも今の値に合わせる（ErfOn を外したときに跳ねない）。
- 15-5 優先順は今までどおり：設定異常 ＞ トラッキング ＞ PV 異常 ＞ モード。下流の弁が MAN などのときは、セレクタの TrkAll で全部の調節計をトラッキングにする（PB_Select 4 章）。
- 15-6 MV は MvLo〜MvHi で切る。DIAG bit7 ＝ 外部リセットで計算した。
- 15-7 I-PD（Alg 1）でも、外部リセットのあいだの比例は偏差にかける（PV にかける I-PD の形は、外部リセットの位置形と合わないため。独自）。
