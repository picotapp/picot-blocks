根拠の表記：[一次] は各社の公開マニュアルで確かめたこと（文書番号・章）。「独自」はこのライブラリの設計判断で、理由を書く。

## 1. 役割

最大 3 つの入力から、高・低・中のどれかを選んで出す。使い方は 2 つ：

| 使い方 | 入力 | 出力の先 | 例 |
|---|---|---|---|
| **信号選択** | 伝送器ブロックの PV（2〜3 台） | 調節計の PV、インターロック | 反応器の温度を 3 点で測り、高い方で制御する。冗長の伝送器の中間値 |
| **オーバーライド** | 調節計の MV（2〜3 台） | 出力ブロック（PB_AnaOut） | 普段は流量で制御し、圧力が上がりすぎたら圧力の調節計が弁を絞る（低選択） |

- 1 つのブロックで両方に使う（選び方と、品質の扱いは同じ）。横河・FF・Rockwell は 2 つに分けている（SS と AS、ISEL と CS）[一次 目次] が、違いは「選ばれなかった側への戻り信号を使うか」だけなので、出力を両方持ち、使う側がつなぐかどうかで分ける（独自。論点 1）。

## 2. 選び方

| 設定 `Sel` | 選ぶもの |
|---|---|
| 0 | 高（使える入力の最大） |
| 1 | 低（使える入力の最小） |
| 2 | 中（3 つ使えるときは中央値。2 つなら平均、1 つならそれ） |

- **使える入力**：設定 `Use` のビットが立っていて（未接続の入力を外す）、`Bad1〜3` が FALSE で、数である入力。
- 同じ値なら番号の小さい方を選んだことにする（`SelNo` を決めるため）。
- 使える入力が 0 個なら、**出力を保持して `Bad` = TRUE**（下流の調節計は PvBad で MAN に落ちる）。ALM bit0。
- 中選択で 2 つのとき平均にする理由：2 つでは中央が無い。どちらかに寄せると、Bad になった方がどちらかで動きが変わる（独自。論点 3）。

## 3. 手動の固定（保守）

- 要求の口 項目 1 で、**選ぶ入力を固定できる**（0 自動・1〜3 その入力）。伝送器の 1 台を保守で外すときなど。エンジニアだけ。
- 固定した入力が使えなくなったら、自動に戻さず `Bad` = TRUE（ALM bit0）。理由（独自）：保守中に固定したものを勝手に外すと、なぜ値が変わったか分からない。
- 固定中は STS bit6（操作された値）。

## 4. 選ばれなかった側への戻り信号（オーバーライドで使う）

> **v0.3 でつなぎ方を変えた。** v0.2 の「TrkOn ← Trkn」では、選ばれていない調節計の MV が前の Out と同じになり、弁が片方向にしか動けなかった。DCS と同じ**外部リセット**でつなぐ：
>
> | 調節計 n の入力 | つなぐもの |
> |---|---|
> | `ErfOn` | TRUE |
> | `ErfVal` | セレクタの `Out` |
> | `TrkOn` | セレクタの `TrkAll`（下流の弁が調節計の値を使っていないとき、全部を弁に追従させる） |
> | `TrkVal` | セレクタの `Out` |
>
> 選ばれていない調節計の MV は「選ばれた値 ＋ 自分の偏差の比例分」になる。低選択なら、自分の偏差が「もっと閉じたい」向きになった調節計が選ばれる。`Trk1`〜`Trk3` は「選ばれていない」の表示用に残す（つながない）。

| 出力 | 内容 |
|---|---|
| `Trk1`〜`Trk3` | TRUE：その入力は選ばれていない |
| `Out` | 選んだ値 |

- **つなぎ方**：調節計 n の `TrkOn` ← `Trk`n、`TrkVal` ← `Out`。選ばれていない調節計は MV を選ばれた値に合わせ続けるので、積分が暴走しない（ABB・三菱が明記している問題 [一次]）。
- 選ばれていない調節計は、毎スキャン「選ばれた値 ＋ 自分の ΔMV」を出すことになる。自分の方がより絞りたく（低選択なら小さく）なった瞬間に選ばれる。速度形の PID なので、これで切り替えは滑らか（独自。テストベクタで確かめる）。
- 信号選択では Trk は使わない（つながない）。
- 下流（PB_AnaOut）の戻り信号 BkOk が FALSE のときは、**すべての Trk を TRUE** にし、Out を下流の BkVal にする（全部の調節計を弁に追従させる）。そのための入力 `BkOkIn`・`BkValIn`（つながなければ BkOkIn = TRUE）。

## 5. 設定（`PB_Select_Cfg`、保持領域）

| 設定 | 型 | 既定値 | 範囲 | 要求の口 |
|---|---|---|---|---|
| `Sel` | INT | 0 | 0 高・1 低・2 中 | 変えない |
| `Use` | WORD | 16#0003 | bit0〜2（入力 1〜3 を使う）。1 つ以上 | 変えない |
| `Fix` | INT | 0 | 0 自動・1〜3（保持する値） | 項目 1（エンジニア） |

- 設定異常：Sel・Fix が範囲外、Use が 0、Fix の入力が Use に無い。出力を保持し、Bad = TRUE、Trk はすべて TRUE。

## 6. 時間・初期化

時間を使わない。`Init`：要求の口を処理しない（AnaMon 13-10）。Fix は保持した値のまま。

## 7. 入出力

| 区分 | 名前 | 型 | 内容 | つながないとき |
|---|---|---|---|---|
| 入力 | `In1`〜`In3` | REAL | 入力 | Use で外す |
| 入力 | `Bad1`〜`Bad3` | BOOL | 入力が使えない（伝送器の Bad、調節計の設定異常など） | FALSE |
| 入力 | `BkOkIn` / `BkValIn` | BOOL / REAL | 下流の戻り信号（オーバーライドのとき） | TRUE / 0 |
| 入力 | `Init` | BOOL | | |
| 入力 | 要求の口 | | | |
| 入出力 | `Cfg` | PB_Select_Cfg | 5 章 | |
| 出力 | `Out` | REAL | 選んだ値 | |
| 出力 | `Bad` | BOOL | 使える入力が無い・固定した入力が使えない・設定異常 | |
| 出力 | `SelNo` | INT | 選んだ入力の番号（値が同じなら一番小さい番号。中選択で 2 つの平均のときと、選べないときは 0） | |
| 出力 | `Trk1`〜`Trk3` | BOOL | 選ばれていない（表示用） | |
| 出力 | `TrkAll` | BOOL | 全部の調節計をトラッキングにする（下流の BkOkIn が FALSE・選べない）。調節計の TrkOn へ | |
| 出力 | `STS` / `MODE` / `ALM` / `DIAG` | WORD | | |
| 出力 | `AckSeq` / `Result` | INT | | |

- MODE：0 自動・1 固定（MODE の値は Fix と同じにしない。固定かどうかだけ）。
- ALM：bit0 選べない（Bad）。DIAG：bit1 設定異常・bit2〜4 入力 1〜3 が使えない・bit5 下流が戻り信号 FALSE。
- STS の品質：Bad なら Bad、使える入力が Use より少なければ Uncertain（冗長が減った）。

## 13. 論点（決定済み 2026-11-26：すべて案どおり）

| # | 論点 | 決定 | 理由 |
|---|---|---|---|
| 1 | 信号選択とオーバーライドを 1 つにするか | **1 つ**（Trk を使うかどうかで分ける） | 選び方・品質の扱いが同じ。ブロックの数を増やさない |
| 2 | 入力の数 | **3 つ**（2oo3 の冗長の中間値に要る） | |
| 3 | 中選択で 2 つしか使えないとき | **平均** | 2 つでは中央が無い。別案：低か高に寄せる（安全側の向きをプロセスごとに選ぶ設定） |
| 4 | 固定した入力が使えなくなったとき | **自動に戻さず Bad** | 保守中の固定を勝手に外さない |
| 5 | 冗長の伝送器の「偏差警報」（3 台の値が離れすぎ） | **拡張版** | 偏差の判定点と遅延の設計が要る |

## 15. 細かい決まり（テストベクタと実装の元）

- 15-1 処理の順番：要求の口 → 設定の検査 → 使える入力 → 選ぶ（固定 ＞ 自動）→ 下流の戻り信号 → 状態ワード。時間と保持する状態を持たないので、Init は要求の口を処理しないことだけ。
- 15-2 中選択で 2 つの平均のとき：`SelNo` = 0、2 つとも `Trk` = FALSE（両方が出力に効いている）。3 つのときの中央値は、値が同じなら一番小さい番号。
- 15-3 使えない入力の `Trk` は TRUE（選ばれていない）。
- 15-4 選べないとき（使える入力が無い・固定した入力が使えない・設定異常）：Out を保持、Bad = TRUE、SelNo = 0、Trk はすべて TRUE、ALM bit0、品質 Bad（原因 計器）。
- 15-5 下流の戻り信号 `BkOkIn` = FALSE：Trk をすべて TRUE、Out = BkValIn（数でなければ保持）、DIAG bit5。選び方（SelNo・Bad）はそのまま。BkOkIn はつながなければ TRUE（宣言の初期値。C-4 の例外。初期値の無い PLC では TRUE をつなぐ。PB_DevCore の Perm と同じ）。
- 15-6 品質：選べなければ Bad、使える入力が Use の数より少なければ Uncertain（どちらも原因 計器）。固定中は STS bit6。
- 15-7 DIAG bit2〜4 は、Use に入っている入力が使えないときだけ立てる。
- 15-8 要求の口 項目 1：書ける人はエンジニア（2）。数でないは 8、0〜3 の外は 3（整数かどうかによらず）、0〜3 の中で整数でないは 8、Use に無い入力は 3。
- 15-9 出力 `TrkAll` ＝（BkOkIn が FALSE）または 選べない。どちらのときも Out は 15-4・15-5 のとおり。
- 15-10 Init のスキャンでは BkOkIn を見ない（PB_Pid 14-11 と同じ理由：下流をまだ呼んでいない）。
- 15-11 16 章の未決は、この版で決定（外部リセット。PB_Pid 15 章）。

## 16. オーバーライドの検討の記録（v0.3 で決定）

| # | 論点 | 案 | 理由 |
|---|---|---|---|
| 1 | オーバーライドの作り方 | PB_Pid に外部リセットの入力（`ErfOn`・`ErfVal`）を足す。選ばれていない調節計は MV ＝ ErfVal（＝ セレクタの Out を TI の一次遅れに通した値）＋ K × 偏差。選ばれたら今の MV から速度形で続ける | 選ばれていない調節計の「自分ならこうしたい」が比例分で比べられ、偏差の向きで正しく切り替わる。一次遅れが無いと、切り替わりの境で積分が効きすぎる |
| 2 | Init のスキャンの BkOkIn | 見ない（PB_Pid 14-11 と同じ理由） | 下流をまだ呼んでいないので、戻り信号が既定値（FALSE・0）のまま |
