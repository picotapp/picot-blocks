## 1. 役割

調節計の MV（%）を 2 つの出力 A・B（%）に分ける。例：

| 例 | A | B |
|---|---|---|
| 順に開く（加熱の蒸気弁を 2 つ、小弁 → 大弁） | MV 0〜50 % → A 0〜100 % | MV 50〜100 % → B 0〜100 % |
| 加熱と冷却（MV 50 % が中立） | MV 50〜0 % → 冷却弁 A 0〜100 % | MV 50〜100 % → 加熱弁 B 0〜100 % |
| 圧力の入れ・抜き（窒素の入れ弁と抜き弁） | MV 0〜50 % → 抜き弁 A 100〜0 % | MV 50〜100 % → 入れ弁 B 0〜100 % |

- 出力はそれぞれ PB_AnaOut の `In` につなぐ。弁の向き（信号が増えると開く・閉じる）は PB_AnaOut が持つので、**ここでは開度（%）で考える**。
- 3 つ以上に分けるときは、このブロックを 2 段にする（基本版は 2 出力）。
- 弁の間の不感帯（両方閉じている区間）や重なり（両方開いている区間）は、範囲の設定で作れる（A を 0〜45 %、B を 55〜100 % にすれば、45〜55 % は両方閉）。

## 2. 換算

出力ごとに 4 つの設定（入力の範囲 InLo〜InHi、そのときの出力 OutLo〜OutHi）を持つ：

- In ≦ InLo なら OutLo、In ≧ InHi なら OutHi、その間は直線。
- **OutLo ＞ OutHi も許す**（入力が増えると閉じる側。上の表の「冷却」「抜き」）。
- InLo ＜ InHi でなければ設定異常。

## 3. 戻り信号（論点 2）

調節計（PB_Pid）へ返す `BkOk`・`BkVal` を、下流の 2 つの PB_AnaOut の戻り信号からまとめる。

| 下流の状態 | BkOk | BkVal（調節計を追従させる MV） |
|---|---|---|
| 両方 BkOk | TRUE | （使わない。今の In） |
| どちらかが BkOk でない | FALSE | 今の In（調節計の MV をその場で止める） |

- **調節計はその場で止まる**（MV が変わらない）。片方の弁が MAN・安全側・AO 異常のときに、もう片方の弁を勝手に動かし続けない（独自。下の理由）。
- 理由：スプリットレンジでは「調節計の MV」と「弁の開度」が 1 対 1 でない（両方閉の区間がある）。BkOk でない弁の開度から MV を逆算すると、区間の端で答えが 1 つに決まらない。ABB はブロックの中で扱っている [一次 ABB 3BSE035981-600 Table 28、中身は未読] が、基本版では「止める」に倒す。
- 逆算して追従する形は拡張版の候補（13 章 論点 2 の別案）。

## 4. 設定（`PB_Split_Cfg`、保持領域）

| 設定 | 型 | 既定値 | 内容 |
|---|---|---|---|
| `InLoA` / `InHiA` / `OutLoA` / `OutHiA` | REAL | 0 / 50 / 0 / 100 | 出力 A |
| `InLoB` / `InHiB` / `OutLoB` / `OutHiB` | REAL | 50 / 100 / 0 / 100 | 出力 B |

- 範囲：すべて 0〜100 %、InLo ＜ InHi。
- **要求の口を持たない**（論点 3）。範囲は試運転で決めるもので、運転中に画面から変えるものではない（Intlk 6 章と同じ考え方）。Modbus には読むだけで出す。
- 設定異常：NaN・無限大、範囲外、InLo ≧ InHi。**設定異常のときは出力を保持し、BkOk = FALSE**。

## 5. 時間・初期化

時間を使わない（dt を持たない）。`Init` も持たない（毎スキャン、入力からそのまま計算する）。

## 6. 入出力

| 区分 | 名前 | 型 | 内容 |
|---|---|---|---|
| 入力 | `In` | REAL | 調節計の MV（%） |
| 入力 | `BkOkA` / `BkValA` / `BkOkB` / `BkValB` | BOOL / REAL | 下流の PB_AnaOut の戻り信号（BkVal は基本版では使わない。拡張版の逆算用に先に受けておく） |
| 入出力 | `Cfg` | PB_Split_Cfg | 4 章 |
| 出力 | `OutA` / `OutB` | REAL | 出力 A・B（%） |
| 出力 | `BkOk` / `BkVal` | BOOL / REAL | 調節計への戻り信号 |
| 出力 | `STS` / `MODE` / `ALM` / `DIAG` | WORD | 状態ワード |

- MODE・ALM：常に 0。DIAG：bit1 設定異常・bit3 In が数でない（出力を保持）・bit4 A が戻り信号 FALSE・bit5 B が戻り信号 FALSE。

## 7. つなぎ方と呼ぶ順番

```
TIC-201(PB_Pid) ─MV→ In  SPL-201(PB_Split) ─OutA→ In TV-201A(PB_AnaOut)
       ▲                       ├─OutB→ In TV-201B(PB_AnaOut)
       │                       ◄─ BkOkA,BkValA ─┘ ◄─ BkOkB,BkValB ─┘
       └─ TrkOn ← NOT SPL-201.BkOk、TrkVal ← SPL-201.BkVal
```

呼ぶ順：調節計 → スプリット → 出力 A・B。戻り信号（出力 → スプリット → 調節計）は、次のスキャンで届く（スプリットは前のスキャンの出力の BkOk を見る。調節計は前のスキャンのスプリットの BkOk を見る）。**2 スキャン遅れる**。テストベクタで、2 スキャンの間に MV が動いても弁が跳ねないこと（BkOk でない弁は自分の値を保持しているので、跳ねない）を確かめる。

## 8. Modbus の並び

| 位置 | 中身 |
|---|---|
| 0〜3 | STS・MODE・ALM・DIAG |
| 4 | VAL：bit0 BkOk・bit1 BkOkA・bit2 BkOkB |
| 5 | 予備 |
| 6〜7・8〜9・10〜11 | In・OutA・OutB |
| 12〜27 | 設定 8 つ（REAL × 8、読むだけ） |

計 28 ワード。

## 9. PICOT HMI

- 画面では調節計の MV と、2 つの弁の開度を見せる。ブロックそのものは画面に出さない（設定の確認用に Modbus へは出す）。
- 試しの画面（熱交換器・反応槽）の加熱・冷却で使う候補（タスク 4）。

## 13. 論点（決定済み 2026-11-26：すべて案どおり）

| # | 論点 | 決定 | 理由 |
|---|---|---|---|
| 1 | 出力の数 | **2 つ**（3 つ以上は 2 段に） | ほとんどのスプリットレンジは 2 弁。入出力が増えると FBD で扱いにくい |
| 2 | 片方の弁が調節計の値を使っていないとき | **調節計をその場で止める**（MV を保持） | 逆算は区間の端で答えが 1 つに決まらない。止めれば、もう片方の弁を勝手に動かさない。別案：BkOk でない弁の開度から MV を逆算して追従（拡張版） |
| 3 | 範囲を画面から変えるか | **変えない**（要求の口を持たない） | 試運転で決める値。運転中に変えると弁の動きの区間が変わり危ない |

## 15. 細かい決まり（テストベクタと実装の元）

- 15-1 換算は REAL で `Out = OutLo + (x − InLo) / (InHi − InLo) × (OutHi − OutLo)`、x は In を InLo〜InHi で切った値。
- 15-2 `BkOkA`・`BkOkB` は**必ずつなぐ**（つながなければ FALSE で、調節計が止まったままになる）。1 つの出力だけ使うときは、使わない側に TRUE をつなぐ。
- 15-3 In が数でない：OutA・OutB を保持、BkVal は最後の数である In、DIAG bit3。BkOk は下流のまま。
- 15-4 設定異常：OutA・OutB を保持、BkOk = FALSE、BkVal は最後の数である In、品質 Bad（原因 計器。AnaMon と同じ）、DIAG は bit1 だけ。直れば次のスキャンから計算する（Init を持たないので、戻りの特別な扱いはない）。
- 15-5 STS：bit0 は常に 1。設定異常のときだけ品質と bit7 を立てる。
